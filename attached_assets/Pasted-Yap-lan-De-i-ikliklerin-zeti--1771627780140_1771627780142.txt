  ---
  Yeni Sorunlar

  1. Renk Tutarsızlıkları (Kritik)

  Tema değişimi sırasında bazı bileşenler eski renk paletinde kalmış:

  AI Credits badge hala dark-mode cyan:
  text-cyan-200 shadow-[0_0_24px_rgba(6,182,212,0.28)]
  Açık arka plan üzerinde text-cyan-200 (çok soluk bir mavi) neredeyse okunamaz. → components/layout/top-navbar.tsx:51-53

  ::selection hala cyan: globals.css:48 — Body amber iken selection cyan, tutarsız.

  globals.css:4 hala --font-inter: Font Outfit'e geçmiş ama :root ve @theme içindeki --font-sans: var(--font-inter) güncellenmemiş. →
  globals.css:4, 8

  Loading sayfası bg-zinc-50 kullanıyor: Ana sayfa stone-50 kullanırken loading zinc-50 — subtil fakat tutarsız. → app/loading.tsx:11

  Loading sayfası layout'u farklı: page.tsx grid max-w-[1600px] kullanırken, loading.tsx flex max-w-7xl kullanıyor. Skeleton ile gerçek
  sayfa yapısal olarak uyuşmuyor. → loading.tsx:14 vs page.tsx:28

  Skeleton renkleri zinc-200: Projenin geri kalanı stone-* kullanırken skeleton zinc-200 ve border-zinc-200. → thread-card-skeleton.tsx:5,
   loading.tsx:19,27,35

  Auth sayfasındaki disabled uyarı hala dark-mode renkleri:
  bg-amber-500/10 text-amber-100
  Light mode'da text-amber-100 görünmez (beyaza yakın bir renk açık arka plan üzerinde). → app/auth/page.tsx:41

  2. Wiggle Animasyonu Bozuk

  globals.css:15 — translateX() parametresiz. Bu geçersiz CSS, animasyon çalışmaz:
  transform: translateX();  /* ← boş parametre */
  translateX(0) olmalı. → app/globals.css:15

  3. Mimari/Yapısal Sorunlar

  proxy.ts hala düzeltilmemiş: Dosya adı proxy.ts ve fonksiyon adı proxy. Next.js middleware olarak çalışması için dosya middleware.ts
  olmalı ve fonksiyon adı middleware olmalı. → proxy.ts:5

  RightSidebar "use client" eklendi ama gereksiz olabilir: Sadece onSubmit placeholder alert'i için client component yapılmış. Server
  Action kullanılsaydı server component kalabilirdi. → components/layout/right-sidebar.tsx:1

  glass-label CSS sınıfı hala kullanılmıyor: Light mode'a uyarlanmış ama hiçbir bileşen referans vermiyor. Dead code. → globals.css:52-57

  cyan-glow CSS sınıfı da kullanılmıyor: → globals.css:59-61

  4. Erişilebilirlik Kalan Sorunları

  Thread preview image'da generic alt text: "Thread preview image" her kart için aynı. Anlamlı değil, thread başlığını içermeli. →
  components/feed/thread-card.tsx:65

  Mobilde arama hala erişilemez: hidden md:flex ile gizleniyor, mobilde alternatif yok. → top-navbar.tsx:39

  BottomTabNav'da aktif sekme göstergesi hala yok: Tüm butonlar aynı text-stone-500 rengiyle. aria-current="page" da yok. →
  bottom-tab-nav.tsx

  Mobilde sidebar içeriklerine erişim hala yok: Kategoriler ve AI Agent mobilde kayıp.

  5. Tasarım Kararsızlığı: Dark ↔ Light

  PRD ve architecture.md'de açıkça belirtilmiş:
  "Strictly Dark Mode default to emphasize the gloss of automotive paint photos"

  Ancak proje artık tam light mode. Bu bilinçli bir karar olabilir, ama:
  - Araç detaylama fotoğrafları (siyah boya, gloss, swirl marks) koyu arka plan üzerinde çok daha etkileyici görünür
  - Rakip detailing toplulukları genellikle koyu tema tercih eder
  - BeforeAfterSlider görselleri light mode'da daha az dikkat çekici
